# Digital Nurture Java FSE Upskilling

This repository contains upskilling and training tasks completed as part of the Java FSE (Full Stack Engineering) program.

## Folder Structure

The exercises are structured as follows:

```
JAVA FSE/
└── UPSKILLING/
    ├── HTML/
    │   └── Module1-HTML.html
    ├── CSS/
    │   └── Module1-CSS.html
    ├── JS/
    │   └── Module1-JS.html
    ├── BOOTSTRAP/
    │   └── Module2-BOOTSTRAP.html
    ├── JAVA/
    │   └── Module3-java
    └── SQL/
        └── Module2-SQL
```

## Technologies Explored

* **HTML5**: Form validations, local storage, geolocation, event handlers, canvas, audio, and video controls.
* **CSS3**: Stylesheets, selectors, formatting, layout, transitions, and animations.
* **JavaScript**: DOM manipulation, event listeners, local storage management.
* **Bootstrap**: Responsive design and components (Bootstrap 5).
* **Java**: Upskilling tasks covering core Java concepts.
* **SQL**: Database queries, schemas, and structure.
